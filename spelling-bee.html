Spelling Bee — Prelim

Every result goes into one shared school record, whichever computer it came from. There are no files to collect and nothing to merge afterwards.

The event code is the important field. Every computer must use exactly the same code, or the results will land in separate records. The PIN is stored with the event the first time it is created — other computers joining the same code cannot change it, so choosing a different PIN elsewhere gives nobody access to the results.
